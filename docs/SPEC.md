# 未知の生命体 仕様(実装済み / 未決定)

## 実装済みの決定
| 項目 | 決定内容 |
|---|---|
| 育成サイクル | 月曜に誕生、日曜の夜までの答えと餌は月曜の朝に反映して完成。前の週の子は「さいきんの子」へ。 |
| 質問 | 1日最大3問(朝6時・昼12時・夜19時)。答えなくてもOK。週ごとに57問のプールから20問を選ぶ。 |
| 反映のタイミング | 問いも餌も翌朝にまとめて反映。行動のたびに「きざし」の文章だけ出す。 |
| 餌と死 | 餌は2日(48時間)に1回あげないと死ぬ。餌をあげるとゲージは満タンに戻る。死んだ子は「星になった子」として残り、すぐ新しい子を迎えられる。 |
| 基本構造 | 中心に球体は必ず存在。器官は体に接続するもの(突起・膜・外殻など)と、周囲に浮遊するもの(環・衛星・蛍群など)の両方。 |
| パーツ | 60種類。性質の組み合わせで出現(1体の性質は最大3つ、性質ごとに器官は最大2つ)。 |
| 連続値 | 突起の長さ・歪み・透明度・発光・大きさ・模様の密度・浮遊の大きさの7つ(0〜1)。答えと餌でゆっくり動き、毎日少しずつ揺らぐ。 |
| 個体差 | 体の形10種 × 模様9種 × 目10種 × 器官ごとの数・向き・大きさ・色みの変化 × 連続値7つ × 31ビット近いシード。20,000体の試験で、同じ見た目は0件。 |
| 性格 | 5つの性質の偏りから決まる(用心ぶかい・のんびり・がんこ・きまぐれ・さびしがり等)+「くせ」12種。話しかけ・なでたときの反応が変わる。 |
| 餌の入手 | ひろいもの(毎日1回、無料。餌が空っぽなら何度でも)とクエスト報酬。珍しい餌は演出だけが派手で、育成上の強さは同じ。 |
| クエスト | 問いに答える / 3問すべて / ごはん / なでる5回 / 広場をのぞく / 友達とくらべる。連続ログインの報酬はなし。 |
| 友達 | サーバーなしで動く「友達に送るリンク」。リンクを開くと友達の子が広場に来て、くらべられる。 |
| ランキング | 強さではなく「めずらしさ(注目度)」。課金で有利にならない。 |
| 画像書き出し | 完成した子をPNGで保存・共有。 |

## 未決定(開発前に決めたいこと)
