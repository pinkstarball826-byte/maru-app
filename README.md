# 未知の生命体 (maru-app)

白い球体の生き物を1週間かけて育て、友達と広場で見比べるアプリ。ビルド不要(静的ファイルだけ)。

## 公開ページ
https://claude.ai/artifact/Hps6A9q7e4m1KkAHjYggty (claude.ai 上。友達に見せるには、ページの「共有」から相手を招待する)

## 動かし方
`maru-app` フォルダで `python3 -m http.server` を実行し、ブラウザで http://localhost:8000 を開く。

## 構成
- `index.html` 画面の骨組み
- `src/style.css` 見た目
- `src/app.js` ロジックと描画(下のメモ参照)
- `src/shim.js` 共有機能の差し替え口(今は端末内保存のみ)

## 決まっていること
- 世界観: 不思議・少しポップ。最初は顔のない白い球体(水のような透明感)。
- 1週間(月曜〜日曜)で1体。問いは朝6時・夜19時。答えと餌は溜めて、翌朝に姿へ反映。
- 隠し性質は5つ(感知・流動・集積・分裂・共鳴)。1体で持てるのは最大3つ。器官は60種類(性質ごとに最大2つまで育つ)。
- 同じ器官でも、数・向き・大きさ・色みが個体ごとに変わる。さらに体の形(10種)・模様(9種)・色相・目(10種)も遺伝子で決まるので、同じ姿はほぼ出ない。
- 目は器官「単眼器官」が生えたときだけ出る。
- 属性は水・草・火・氷・雷・星から1つ(最初の質問で決まる)。
- 餌は8種類(結晶片・光の粒子・液体の雫・影の粒子・風の羽根・夢のけむり・星くず・琥珀の蜜)。種類ごとに演出が違う(canvas)。
- 質問は57問のプールから週ごとに20問(+属性の質問)を選ぶ。
- 餌はひろいもの(毎日1回・無料)とクエスト報酬で手に入れる。
- 友達に送るリンクで、友達の子を広場に呼んで見くらべられる(サーバー不要)。
- 詳しい仕様と未決定事項は `docs/SPEC.md`。
- 餌は2日(48時間)に1回あげないと死んでしまう(星になった子はすぐ新しい子を迎えられる)。
- 終わった子は「さいきんの子」(7日分)に残り、「とっておく」で保存。

## ファイル
- `src/data.js` 器官60・質問プール・餌・属性など中身のデータ
- `src/art.js` 追加器官30の絵、体の形/模様の遺伝子、名前と希少度
- `src/pet3d.js` ホーム画面の3D表示(three.js r128。透明な膜・体積のもや・泡・60器官の3D版)。広場などは2DのSVG
- `src/fx.js` 背景の星空、まわりの粒子、追加の餌演出、進化の全画面演出

## app.js の目印
- 先頭付近の `INSTANT`(true で変化がその場で出るテスト用)、`RV`(上げると一度だけ今週の子をリセット)
- `PARTS` 30器官の定義 / `Q` 質問 / `OMEN` きざし文 / `FOODS` 餌
- `applyPending()` 翌朝の反映ロジック / `petSVG()` 生き物の描画 / `fx()` 餌のエフェクト

## 次にやること(候補)
1. `shim.js` を本物のバックエンドに差し替える(ログイン、広場、ランキング)
2. 器官30種の絵を作り込む(今は単純な図形)
3. 属性を増やす・属性ごとの器官の見た目を変える
4. 餌の入手方法(クエスト報酬・ひろいもの)
5. 画像書き出し(完成した子をシェア)
6. 課金(見た目・保存枠。ランキングに有利なものは避ける)
7. スマホアプリ化(PWA か Capacitor)

## 注意
- 保存は `localStorage`(キー `maru-v5` と、持ちもの・クエスト・友達用の `maru-meta`)。端末を変えると引き継がれない。
- 以前の公開ページ(Claude上)の記録は、このプロジェクトには引き継がれない。
